# Общий регламент соревнований по робототехнике портала РобоФинист

*Версия 8.1 от 20.09.2026*

Цель настоящего регламента - единые правила и стандарты проведения соревнований по робототехнике в России и странах содружества с использованием единого информационного пространства портала РобоФинист. Настоящий регламент разработан при поддержке Союза национальных соревнований по робототехнике и методического комитета Международного фестиваля робототехники «РобоФинист». 

Актуальная и действующая версия настоящего регламента: [robofinist.ru/regmain](http://robofinist.ru/regmain)

Электронная почта по вопросам всех регламентов: [method@robofinist.ru](mailto:method@robofinist.ru)

## Термины и определения

Каждый из терминов, приведенных ниже в таблице, используется в регламентах в данном в таблице значении.

| **Термин** | **Определение** |
| --- | --- |
| Докладчик | команда, представляющая проект на оценку или рецензирование |
| Достигнуть (достигнуть финиша, объекта, контрольной точки, линии на полигоне и т.д.) | факт фиксации робота над целевой зоной или объектом, при котором перпендикулярная проекция габаритов робота на плоскость полигона хотя бы частично пересекается с этим объектом |
| Дисциплина  | соревновательная программа, проводимая по единому частному регламенту, по итогам которого осуществляется определение победителей  и призеров |
| Заезд (заплыв, полет) | единичный акт выполнения участником задания дисциплины |
| Заявка (команда) | объединяющая совокупность участников, руководителей, роботов, участвующая в одной или нескольких дисциплинах в одном мероприятии |
| Зона старта (финиша) | явно обозначенный участок полигона, в котором должен находиться робот в начале (конце) выполнения задания полигона. Граница зоны старта является частью зоны старта |
| Зона соревнований | ограниченное пространство (с помощью ограждений или разметки), в котором располагаются полигоны, судейский инвентарь, судьи и оператор робота, выполняющего попытку в данный момент |
| Карантин | зона (место) для изолированного от участников и третьих лиц размещения роботов (во избежание несанкционированного изменения программы и/или конструкции робота) |
| Категории соревнований | определенные в рамках соответствующих регламентов  конкретизированные варианты проведения отдельной дисциплины. <br>Примечание: аналогичны общеупотребимым спортивным понятиям: категории,  лиги, подвиды, классы. Категории соревнований могут определяться: по возрасту допускаемых участников; по техническим требованиям к роботам и/или полигонам; по иным критериям |
| Клинч | взаимный захват или тесное прижатие друг к другу, при котором роботы временно теряют возможность активно действовать, не перемещаются или кружатся на месте |
| Круговая система | система организации парных состязаний, при которой каждая команда играет с каждой другой командой этапа |
| Летательный аппарат | робот, поддерживаемый в атмосфере за счет взаимодействия с воздухом. <br>Примечание: конструктивно может быть выполнен в виде самолета, винтокрылого аппарата (в т.ч., вертолет и мультикоптер), планера, махолета или дирижабля |
| Линия старта (финиша) | линия, при пересечении которой начинается (завершается) заезд. <br>Примечание: пересечение фиксируется относительно проекции робота |
| Матч | совокупность раундов в состязании между командами. Минимальный зачетный элемент парного вида соревнований |
| Мероприятие | совокупность одной или нескольких программ, организованных и проводимых в одно время организационным комитетом, объединённых общей концепцией, расписанием и единой системой управления |
| Методический комитет | коллегиальный экспертный орган, который отвечает за разработку регламентов, критериев судейства и методик подготовки участников дисциплины |
| Модификация робота | преобразование  и/или видоизменение  конструкции робота или его управляющей программы с сохранением базового функционала |
| Образовательный конструктор | стандартизированный производителем набор робототехнических деталей,  предназначенный для обучения робототехнике<br>Примечание: основные требования к образовательным конструкторам, используемым в соревнованиях: <br>1. все элементы конструктора представлены на сайте производителя или его представителей и находятся в свободной продаже; <br>2. электронные компоненты помещены производителем в пластиковые корпуса и предполагают многократное использование в разных моделях роботов; <br>3. все электрические элементы оснащены разъемами и коннекторами для многократного беспаечного соединения. Дополнительные требования и список образовательных конструкторов приведены в п. 3.5 |
| Олимпийская система | система организации парных состязаний, при которой команда выбывает из этапа после первого проигрыша |
| Оператор | участник команды, допускаемый в зону соревнований для проверки полигона, запуска робота или управления им |
| Полигон | пространственно ограниченная и регламентированным образом оборудованная территория для выполнения задания заезда или проведения матча |
| Попытка | последовательно повторяемое выполнение заезда в одном и том же этапе |
| Портал (Мультидоменный портал) | единая информационная система и сложный составной объект интеллектуальных прав, состоящий из совокупности функционально, программно и логически связанных между собой сайтов (сервисов) в сети «Интернет», расположенных на различных доменных именах, включая, но не ограничиваясь: robofinist.ru, robofinist.org и robofinist.by. Все сайты портала имеют общую программно-аппаратную базу, единую систему сквозной аутентификации пользователей и управляются администрацией |
| Предпоказ | краткая устная презентация проекта, сопровождаемая слайдами |
| Препятствие | неподвижный или движущийся объект регламентированных характеристик, не позволяющий или затрудняющий движение по трассе |
| Программа мероприятия | составная часть мероприятия, в рамках которой на конкретном мероприятии проводится дисциплина. Может быть несоревновательной |
| Раунд | составная часть матча, ограниченный промежуток времени, на протяжении которого происходит противоборство роботов |
| Рецензент | команда, которая осуществляет рецензирование |
| Робот | объединенное единым конструктивным оформлением автоматическое устройство с обратной связью и определенной степенью автономности, предназначенное для выполнения механических операций в окружающей среде: перемещения, манипулирования или позиционирования. Робот имеет три неотъемлемых составляющих: механическую, электронную, программную, каждая из которых играет существенную роль в его работе. В состав робота входят: датчики (сенсоры) для восприятия окружающей среды; двигатели, обеспечивающие движение всей конструкции и/или ее отдельных частей; программируемый контроллер, который посредством  заложенной исполняемой программы обрабатывает данные датчиков и управляет работой двигателей. Использование внешних  управляющих сигналов (команд) допустимо только как дополнительная опция |
| Роботизированное устройство | устройство, в основном обладающее характеристиками робота, но не имеющее достаточной степени подвижности, автономности или возможности перепрограммирования |
| Руководитель (тренер, наставник) | совершеннолетний представитель команды, указанный в заявке, несущий ответственность за соревновательные выступления участников во время проведения мероприятия (даже без личного присутствия на мероприятии), не является участником, не может являться оператором |
| Система «старт-финиш» | электронная система измерения времени прохождения роботом кольцевой трассы. Сенсор фиксации прохождения робота располагается на высоте до 3 см |
| Соревнования (состязания) | мероприятие состязательного характера, направленное на достижение каждой команды максимально возможного результата и конструктивный обмен опытом с другими участниками. В ходе соревнований проводится определение победителей. Проведение нормируется соответствующим регламентом, размещенным на портале. Соревнования проводятся среди зарегистрированных на портале участников. Контроль над соблюдением регламента соревнований и определение победителей и призеров производится судьями. Термин «соревнования» употребляется во множественном числе |
| Судья | лицо, уполномоченное организационным комитетом соревнований контролировать соблюдение регламента соревнований и фиксировать их результаты |
| Связанные участники | участники разных команд из одной или нескольких организаций, в которых происходит тесное взаимодействие и обмен результатами разработок. |
| Трасса | предполагаемый путь движения робота при прохождении полигона конкретной дисциплины |
| Техническая зона (зона подготовки) | Зона, в которой расположены рабочие места для размещения роботов и отладочного оборудования участников, а также тренировочные полигоны |
| Участник | лицо, чья заявка на участие в конкретном соревновании принята организационным комитетом.  <br>Примечание: также может употребляться для обозначения зарегистрированной команды, состоящей из нескольких персональных участников |
| Этап | составная часть программы мероприятия, по итогам которой определяется ранжированный список участвующих команд |

## 1. Общие положения

<a id="section-1-1"></a>

### 1.1. Общие положения

- Положения настоящего «Общего регламента соревнований» по умолчанию дополняют все частные регламенты дисциплин, проводимых на портале РобоФинист.
- В случаях, когда положения регламента конкретной дисциплины вступают в противоречие с «Общим регламентом соревнований», приоритет отдается положениям регламента конкретной дисциплины.
- В случаях, когда действия робота или операторов не описаны регламентом соревнований, считается, что такие действия допустимы.
- В случае, если в регламенте присутствует подтвержденное методическим комитетом противоречие или двоякость чтения пункта регламента, то допускается применять все вариации его исполнения. Предоставление таких подтверждений возлагается на участников соревнований.

<a id="section-1-2"></a>

### 1.2. Организация соревнований

- Для проведения мероприятия создается организационный комитет.
- Ответственным за мероприятие назначается руководитель организационного комитета.
- Для судейства соревнований создается судейская коллегия, из состава которой организаторами назначается главный судья.
- Ответственным за судейство и исполнение регламентов на соревнованиях является главный судья.
- По усмотрению организационного комитета (например, при малом количестве проводимых дисциплин в рамках мероприятия) каждый судья может быть назначен на несколько дисциплин одновременно.
- Для рассмотрения апелляций организационным комитетом создается апелляционная комиссия.
- Для формализации организационно-методических вопросов соревнований организационный комитет разрабатывает «Положение о проведении соревнований».

<a id="section-1-3"></a>

### 1.3. Правила поведения участников соревнований

- В техническую и соревновательную зоны допускаются только участники соревнований без тренеров и руководителей команд, если иное не предусмотрено регламентом соревнований.
- Во время соревнований участникам запрещено:
    - наносить ущерб площадке, полям, материалам и оборудованию, используемым для соревнований, а также роботам других команд;
    - применять опасные предметы или предпринимать действия, которые могут препятствовать проведению соревнований;
    - агрессивное поведение по отношению к членам других команд, зрителям, судьям и персоналу, использование оскорбительной лексики;
    - приносить еду и напитки в зону соревнований;
    - предпринимать любые иные действия, которые судья может посчитать препятствием проведению соревнований или нарушением их регламентов;
    - использовать сотовый телефон или иные проводные/беспроводные средства связи в зоне соревнований, если иное не указано в регламенте дисциплины;
    - касаться своего или чужого робота или полигона без разрешения судьи, если иное не указано в регламенте дисциплины;
    - осуществлять любое взаимодействие с роботами других участников, в том числе управление ими.
- Во время соревнований руководителям команд запрещено:
    - находиться в зоне соревнований и в технической зоне;
    - выполнять какие-либо манипуляции с роботом.

<a id="section-1-4"></a>

### 1.4. Влияние внешних факторов

- Организаторы обязаны сделать все возможное для обеспечения наилучших условий проведения соревнований. Вместе с тем конкретные условия проведения соревнований могут не соответствовать ожиданиям участников. В этой связи:
    - роботы должны быть подготовлены к тому, что на поверхности полигона могут быть неровности размером до 5 мм, рисунок полигона выполнен с незначительным отклонением цветов и размеров;
    - командам следует быть готовыми к тому, что не будет предоставлен ожидаемый ими направленный, рассеянный и/или интенсивный свет, а также к возможному применению фотовспышки. Команды должны быть готовы откалибровать датчики своих роботов в имеющихся условиях освещения;
    - команды, использующие электронные компасы в качестве датчиков, должны учесть возможное влияние электромагнитных помех (в том числе от элементов инвентаря, наводок линий электропитания и пр.). Команды должны быть готовы откалибровать такие датчики.

<a id="section-1-5"></a>

### 1.5. Типовые элементы инвентаря

- Оптимальным является использование следующих материалов и предметов:
    - печатная основа полигона изготавливается из литого баннера плотностью 400-500 г/м2;
    - элемент «кегля» изготавливается из стандартной металлической емкости для напитков (330 мл), обернутой листом бумаги;
    - элемент «муфта» представляет собой стандартную пластиковую двухраструбную канализационную муфту серого цвета диаметром 50 мм, высотой 100+/-10 мм;
    - препятствие «кирпич» представляет собой кирпич по ГОСТ одинарного размера, по возможности обернутый бумагой;
    - препятствие «горка» представляет собой неподвижно закрепленную на полигоне прямую треугольную призму с основанием в форме тупоугольного равнобедренного треугольника или четырехугольную призму с основанием в виде трапеции, размещаемой на полигоне на наибольшей боковой грани и имеющей ширину (b), длину (l), высоту (h), определяемые соответствующими регламентами дисциплин;
    - препятствие «камни» изготавливается из облицовочного камня толщиной 20+/-10 мм, обломков камней или полосы щебня мелкой фракции;
    - препятствие «стиральная доска» представляет собой последовательность из 5 или более неподвижных параллельно установленных вдоль трассы брусков (реек), предпочтительно с полукруглым поперечным сечением. Бруски устанавливаются перпендикулярно трассе с интервалом, как правило, равным ширине бруска. Бруски могут быть изготовлены как единый конструктивный элемент;
    - препятствие «бордюр» представляет собой брусок из произвольного материала, произвольного цвета, прямоугольного, трапециевидного или скругленного поперечного сечения, неподвижно закрепленный на полигоне. Длина бруска – больше или равна ширине робота в данной дисциплине.

<a id="section-2"></a>

## 2. Регистрация на соревнования

<a id="section-2-1"></a>

### 2.1. Подача Заявки

- Подать заявку на соревнования могут только зарегистрированные на портале пользователи.
- В системе регистрации на соревнования необходимо подавать заявки на робота (группу роботов) и команду его разработчиков.
- Один робот может быть зарегистрирован в каждой дисциплине только один раз.
- Зарегистрировать робота и команду на соревнования может как руководитель, так и один из участников команды.
- К заявке могут быть приложены материалы роботов в формате текстового описания, фотографий, видео, или в другом файловом представлении. Все материалы должны соответствовать роботам и быть разработаны участниками команды. Организационным комитетом или регламентами дисциплин могут быть установлены материалы обязательные при подаче заявки.
- Допускается модификация одного и того же робота для участия в различных дисциплинах.
- Команда состоит из участников, непосредственно выполняющих соревновательные действия, и одного или нескольких руководителей.
- Руководитель обязателен для команды с участниками младше 18 лет, иначе команда не может быть зарегистрирована.
- Руководитель не обязателен в команде, состоящей из участников старше 18 лет. В этом случае ответственность и функции взаимодействия с организационным комитетом возлагаются на старшего по возрасту участника.
- Один участник может состоять только в одной команде в рамках одного вида соревнований.
- После подачи заявки каждый участник команды должен в личном кабинете подтвердить свое участие.

<a id="section-2-2"></a>

### 2.2. Обработка заявки

- После подтверждения всеми участниками команды и руководителем команды заявка автоматически переходит в статус «На рассмотрении».
- Рассмотрение заявки производит организационный комитет мероприятия. По его итогам организационный комитет может:
    - подтвердить заявку;
    - отклонить заявку;
    - потребовать уточнений по заявке;
    - внести изменения в заявку по просьбе команды.
- После подтверждения заявки и до окончания регистрации внесение любых изменений в заявку производится участниками команды.
- После окончания регистрации заявок внесение изменений в заявки производится только организационным комитетом по его усмотрению и после обращения команды. По усмотрению организационного комитета в редактировании заявки может быть отказано без объяснения причин.
- Внесение изменений в материалы роботов допускается до начала мероприятия, если иное не установлено организационным комитетом.
- Любые заявления команды принимаются организационным комитетом через комментарии к заявкам или другим утвержденным организационным комитетом способом.

<a id="section-2-3"></a>

### 2.3. Конкурсный отбор по материалам заявки

- В случаях, установленных регламентами конкретного мероприятия, проводится дополнительный конкурсный отбор по предоставляемым при регистрации заявки фото-, видео-, текстовым материалам.

<a id="section-3"></a>

## 3. Ограничения на участие

<a id="section-3-1"></a>

### 3.1. Общие ограничения

- Участники младше 9 лет могут принимать участие в соревнованиях под ответственность руководителей и родителей, с учетом возможности стресса для детей младшего возраста.
- Регламентом дисциплины, а также организаторами конкретного Мероприятия, могут быть установлены ограничения на численность команды, как на минимальное, так и на максимальное число участников.

<a id="section-3-2"></a>

### 3.2. Общие требования к роботам

- Запрещается использовать в роботе источники питания с суммарным номинальным напряжением выше 35 В. Запрещается использовать сетевое подключение.
- Робот должен быть безопасен, использование огнеопасных веществ запрещено.
- Робот не должен каким-либо образом повреждать полигон или выполнять действия по изменению конфигурации трассы (например, оставлять полосы или стирать исходную линию трассы).
- Роботы должны быть собраны исключительно самими участниками. Не допускается использование готовых покупных моделей и специализированных для конкретных соревнований наборов компонентов, если иное не предусмотрено регламентом дисциплины.
- Программа, выполняемая роботом, должна быть написана исключительно самими участниками команды.
- Любой представитель судейской коллегии вправе назначить Техническое интервью, в ходе которого участник должен объяснить конструктивное исполнение и алгоритм действия робота, а также продемонстрировать загрузку программы с компьютера в память робота. Проведение технического интервью описано в Приложении А.
- Техническое интервью может быть назначено любой команде в любой момент до окончания мероприятия. Судьи принимают решение о его проведении самостоятельно, но могут учитывать запросы от других команд. При поступлении обоснованного запроса техническое интервью должно быть проведено также для команды, от которой поступил запрос.
- Автономный робот должен иметь кнопку запуска алгоритма действий робота. В качестве такой кнопки допускается использовать любые коммутационные элементы ручного управления, установленные на самом роботе, или пульт, позволяющий выполнять запуск дистанционно. Использование в этих целях смартфона, компьютера или отладочного устройства запрещено. После дистанционного запуска оператор должен как можно скорее убрать пульт из рук. Любое взаимодействие с коммутационными элементами после запуска будет расцениваться как внешнее управление роботом.
- Робот должен иметь кнопку остановки действий робота. Рекомендуется, чтобы такая кнопка приводила к размыканию источника питания. Допускается использовать любые коммутационные элементы ручного управления, в том числе совмещать с кнопкой запуска.
- Перед началом соревнований судьи проводят техническую инспекцию с целью проверки роботов на соответствие требованиям регламента. В инспекцию, в зависимости от требований регламента, может входить проверка массы, габаритных размеров, напряжения источника питания, конструктивных особенностей. В инспекцию входит проверка соответствия материалов робота, приложенных к заявке, и самого робота.
- Для проверки соответствия массы робота ограничениям регламента используются весы. Погрешность весов не должна превышать 5%, если иное не предусмотрено регламентом дисциплины.
- Для проверки соответствия размера робота ограничениям конкретного регламента используются специальные измерительные конструкции, выполненные в виде прямоугольных параллелепипедов, если иное не указано в регламенте дисциплины. Измерительные конструкции изготавливаются из прозрачного материала, с внутренним размером, равным предельно допустимому размеру робота. Робот должен полностью и без усилий помещаться в измерительную конструкцию, оставаясь в стартовом положении. Допускается изготавливать измерительные конструкции в виде объемных рамок.
- Порядок проверки размеров: робот в стартовом положении устанавливается на горизонтальной поверхности, затем на него в направлении сверху вниз опускается измерительная конструкция. Проверка считается пройденной, если нижние ребра измерительной конструкции полностью коснулись поверхности, а при подъеме измерительной конструкции не происходит отрыва робота от поверхности.
- Для проверки напряжения робота судьи измеряют фактическое напряжение на выводах источника питания с помощью вольтметра (мультиметра). Проверка номинального напряжения проводится по маркировке на корпусе источника питания или по его технической документации, при этом судьи руководствуются только заявленным номиналом, без выполнения измерений. Проверка считается пройденной, если напряжение соответствует ограничениям регламента.
- Робот считается идентичным собственной модификации.
- Два робота считаются различными в том, и только в том случае, если они могут быть предъявлены в функционирующем состоянии одновременно.
- Роботам следует иметь очевидное программное И конструктивное отличие от других роботов, которое дает им возможное преимущество и не является плагиатом.
- В рамках одних соревнований команды связанных участников с конструктивно похожими роботами могут быть подвергнуты технической инспекции с последующей дисквалификацией или выделением в отдельный соревновательный этап.
- В инспекцию входит:
    - определение уровня знания технической конструкции своего робота;
    - определение уровня знания и понимание программного кода, алгоритма программы, умение объяснить его.
- Основанием для дисквалификации служит:
    - незнание технической и конструктивной части робота;
    - отсутствие понимания алгоритма программы, затруднения с объяснением назначения тех или иных блоков кода, а также схожесть кода инспектируемых роботах. Под схожестью кода следует понимать одинаковое название функций, их структура и расположение.
- Подтверждением уникальности робота может служить инженерный журнал, подтверждающий факт самостоятельного проектирования и сборки робота.
- Команды со схожими роботами участников, прошедшие техническую инспекцию, по решению организационного комитета могут быть выделены в отдельный соревновательный этап, из которого в основные соревнования выходит одна команда.
- При неоднократных дисквалификациях команд одного руководителя по итогам технического интервью, на руководителя может быть наложено ограничение на количество допускаемых на мероприятия команд в одной категории: не более одной команды на дисциплину. По решению организационного комитета мероприятия ограничение может действовать до конца сезона или до следующего мероприятия данного уровня включительно.

<a id="section-3-3"></a>

### 3.3. Общие требования к полигонам

- Полигоны должны соответствовать следующим критериям:
    - безопасность материала;
    - равномерность и химическая инертность покрытия;
    - соблюдение размерных и прочих требований частных регламентов дисциплин.
- Полигон может иметь нанесенный логотип и/или название компании-организатора мероприятия.
- В случае проведения мероприятий через портал РобоФинист robofinist.ru, рекомендовано нанесение логотипа РобоФинист. Логотип доступен для скачивания по ссылке: [https://robofinist.ru/logo](https://robofinist.ru/logo).

<a id="section-3-4"></a>

### 3.4. Ограничения, определяемые категорией соревнований

- Отдельные дисциплины проводятся с разделением по образовательным, возрастным или конструктивным категориям. Принять участие в таких соревнованиях могут только участники, соответствующие установленным требованиям настоящего пункта регламента.
- Для разделения дисциплины на категории к названию дисциплины добавляется название категории и текущий регламент дисциплины автоматически дополняется требованиями установленными настоящим пунктом регламента.
- Команда участников с одним и тем же роботом (или командой роботов) может принять участие только в одной из категорий данной дисциплины.
- В каждой категории победитель определяется независимо от других категорий.
- Образовательные категории:
    - «Для начинающих» – команда, все участники которой соответствуют следующим критериям:
        - участник после наступления 11-летнего возраста занимается робототехникой не более 1 года и в календарный год проведения соревнований ему исполняется 13 или менее лет;
        - участник младше 12 лет вне зависимости от продолжительности обучения робототехнике, который не принимал участие в данной категории соревнований до текущего учебного года.
    - «Для продолжающих» – команда, участники которой соответствуют следующим критериям:
        - хотя бы один участник занимается робототехникой более 1 года после наступления 11-летнего возраста или в календарный год проведения соревнований ему исполняется 14 или более лет;
        - хотя бы один участник возраста младше 12 лет принимал участие в соответствующей категории «для начинающих» или «для продолжающих» до текущего учебного года;
        - все участники команды соответствуют критериям «для начинающих», но приняли решение принимать участие в категории для продолжающих.
- Возрастные категории:
    - «Младшая» – к участию допускаются команды, в которых самому старшему участнику в календарный год проведения соревнований исполняется 12 или менее лет;
    - «Средняя» – к участию допускаются команды, в которых самому старшему участнику в календарный год проведения соревнований исполняется 13, 14 или 15 лет;
    - «Старшая» – к участию допускаются команды, в которых самому старшему участнику в календарный год проведения соревнований исполняется 16 или более лет. По решению организационного комитета может быть установлен верхний (предельный) возраст самого старшего участника.
- Конструктивные категории:
    - «Образовательные конструкторы» – к участию допускаются роботы, изготовленные из образовательного конструктора (см. п. 1.1. термин «Образовательные конструкторы» и п. 3.5.);
    - «Аналоговые роботы» или «BEAM-роботы» – к участию допускаются роботы, не имеющие программируемого контроллера, логика действий которых построена на основе аналоговых цепей;
    - «Высшая лига» – требований к роботу не предъявляется.
- Приведенное разделение по категориям не является исчерпывающим, отдельными регламентами допускаются иные границы разделения.
- Для отдельных дисциплин соответствующими регламентами могут быть установлены иные методы определения категорий.

<a id="section-3-5"></a>

### 3.5. Ограничения, определяемые категорией «Образовательные конструкторы»

- К участию в данной категории допускаются роботы, собранные из стандартизованных производителем наборов робототехнических деталей, предназначенных для обучения робототехнике. К образовательным конструкторам относятся конструкторы перечисленных фирм, если иное не указано в регламенте дисциплины:
    - Lego (или идентичные аналоги);
    - Fischertechnik;
    - VEX;
    - Huna;
    - TRIK;
    - Robotis;
    - MBot и MBot 2 от MakeBlock;
    - RoboKids;
    - Robotrack;
    - Hitechnic;
    - Mindsensors;
    - Smartbricks;
    - ZMROBO;
    - R:ED;
    - АВРОРА;
    - Ники Робот;
    - Клик;
    - VinciBot.
- К образовательным наборам относятся любые расширения и модификации перечисленных производителей.
- К образовательным конструкторам не относятся Arduino-наборы электроники, в том числе помещенные в корпус производителем.
- Допускается сборка робота из комбинаций различных допустимых образовательных конструкторов.
- В конструкциях роботов допускается использование неэлектронных деталей собственного изготовления:
    - напечатанных на 3D-принтере;
    - изготовленных на лазерном или фрезерном станке;
    - изготовленных ручным инструментом;
    - изготовленных из предметов быта (например, банковская карта, грузило, линейка, картон, оргстекло) и т.д.
- Контроллеры, датчики и моторы могут быть использованы только из образовательного конструктора или его расширений.
- Все электронные устройства должны быть помещены производителем в корпуса и оснащены разъемами и коннекторами, позволяющими многократно соединять их между собой. Элементы самостоятельной пайки недопустимы.
- Допускается использование контроллеров только в том виде, в котором они поставляются производителем. Допускается изменение программного обеспечения контроллера. Источники питания должны соответствовать заявленным производителем параметрам.
- Допускается использование датчиков сторонних производителей, соответствующих по функциональности стандартным датчикам образовательного конструктора.
- Допускается использование самостоятельно разработанных кабелей для подключения датчиков и моторов к контроллеру.
- Запрещается использовать источники питания не по назначению.
- Робот должен использовать для перемещения колеса или гусеницы из образовательного конструктора или его расширений, любые самостоятельные модификации запрещены.
- Запрещено использовать шины изготовленные из силикона или латекса.

<a id="section-3-6"></a>

### 3.6. Дополнительные ограничения, определяемые категорией для начинающих

- Роботы в категориях для начинающих должны быть собраны из образовательного конструктора в соответствии с п. 3.5, если иное не оговорено в регламенте конкретной категории.
- Программа, выполняемая роботом, должна быть написана исключительно самими участниками. Любой представитель судейской коллегии вправе провести проверку, в ходе которой участник должен объяснить конструктивное исполнение и алгоритм действия робота, а также продемонстрировать загрузку алгоритма в память робота с компьютера. В случае отказа или неспособности выполнить требования судьи участник может быть дисквалифицирован.

<a id="section-4"></a>

## 4. Порядок проведения соревнований

<a id="section-4-1"></a>

### 4.1. Общие положения

- Команда может принять участие только в тех дисциплинах, на которые была подана и принята заявка.
- Соревнования проводятся по соответствующему регламенту конкретной дисциплины.
- Команда использует на соревнованиях материалы и оборудование (роботов, комплектующие и портативные компьютеры и т.п.), привезенные с собой. Организационный комитет не предоставляет указанного оборудования, если иное не предусмотрено регламентом конкретной дисциплины или не установлено организаторами конкретного мероприятия.
- В случае непредвиденной поломки или неисправности роботов или иного инвентаря команды, ответственность за их ремонт или замену несут сами команды. Рекомендуется иметь набор запасных деталей, элементов питания и т.п.
- Организаторами конкретного мероприятия или отдельными регламентами может вводиться требование по самостоятельной сборке и программированию роботов оператором или участниками, непосредственно во время соревнования в специально отведенной (технической) зоне.
- Во время проведения соревнований участникам следует:
    - соблюдать порядок и дисциплину, относиться друг к другу, зрителям, судьям, организаторам и участникам других дисциплин с уважением;
    - следовать указаниям судей и организаторов;
    - не портить (загрязнять, приводить в негодность) помещения и инвентарь, используемый для проведения соревнований (покрытия и дополнительные элементы полей, измерительное оборудование и т.п.);
    - следовать установленному организаторами соревнований расписанию, заранее информировать организаторов соревнований или судей о возможных задержках со своей стороны.
- В зоне проведения соревнований допускается нахождение только операторов роботов. Количество операторов от одной команды не может превышать количества роботов этой команды, необходимое для осуществления попытки.
- В зоне проведения соревнований запрещено находиться болельщикам, руководителям и другим участникам команды, не являющимися операторами робота.
- Сборка, настройка, программирование роботов производится исключительно в отведенном организатором мероприятия пространстве (технической зоне). По специальному разрешению судей или организаторов допускается настройка роботов (тренировочные игровые действия) в соревновательной зоне (на полигонах) и строго в отведенное ими время.
- Тренеры и руководители команд допускаются в тренировочную зону исключительно по указаниям (разрешениям) судей или организаторов, если это допускается конкретным Регламентом данных соревнований.
- При введении карантина, после окончания сборки, настройки и программирования, роботы помещаются в него, и извлекаются оттуда исключительно оператором и по соответствующим командам судей. Во время попытки оператору запрещается вводить в робота какую-либо информацию о конфигурации полигона, за исключением калибровки датчиков цвета.
- Факт начала выполнения попытки автоматически означает согласие оператора с тем, что полигон находится в надлежащем состоянии и соответствует регламенту. Если оператор считает, что поле или любой другой элемент полигона находится в ненадлежащем состоянии или не соответствует Регламенту, он должен сообщить об этом судье соревнования до начала попытки.
- Если во время выполнения попытки по независящим от участников причинам изменились характеристики элементов полигона (в том числе динамических) и полигон перестал соответствовать Регламенту, то судьи могут принять решение о переигровки данной попытки или принятия результата выполнения попытки, основываясь на возможности успешного выполнения задания соревнований.
- Ответственность за безопасность роботов лежит на их собственниках и руководителях команд.
- При возникновении несчастного случая по причине неисправности робота и/или вине участника соревнований, ответственность за произошедшее несет руководитель команды.
- Контроль и подведение итогов осуществляется судейской коллегией в соответствии с регламентом соревнований.
- Все спорные моменты, возникающие в период соревнований, разрешаются судьями соревнований, все участники должны подчиняться их решениям.
- Исполнение полигонов допускается изменять (но только в рамках установленных частным Регламентом требований) по усмотрению организаторов конкретных соревнований, в т.ч., непосредственно перед началом соревнований (но не в ходе их). Примеры таких изменений:
    - конфигурация трассы;
    - расположение, вид и количество препятствий.

<a id="section-4-2"></a>

### 4.2. Порядок проведения одиночных видов соревнований

- Каждой команде предоставляется не менее двух попыток на выполнение задания соревнований. Окончательное количество попыток определяется организаторами в день проведения соревнований. В зачет принимается лучший результат из попыток.
- Очередность выступлений участников определяется организаторами в день проведения соревнований.
- Допустимо формирование очередности выступления участников:
    - по убыванию номера заявки;
    - по возрастанию номера заявки;
    - в алфавитном порядке;
    - в случайном порядке.
- В случае, если команда не может выполнить попытку в установленном порядке в отведенное время, то с разрешения судей попытка может быть перенесена после выполнения попытки следующей команды, но не более одного раза.
- В случае неявки команды в отведенное время объявляется дисквалификация попытки.

<a id="section-4-3"></a>

### 4.3. Порядок проведения парных видов соревнований

- Порядок проведения парных видов соревнований определяется регламентом конкретной дисциплины или организаторами в день проведения соревнований и может быть видов:
    - Круговая система — система розыгрыша, при которой каждый участник играет с каждым. Критерии определения победителя в круговой системе в порядке убывания приоритетов:
        - количество выигранных матчей;
        - количество проигранных матчей;
        - количество ничьих;
        - количество набранных очков;
        - количество проигранных очков;
        - стыковые матчи (результат сыгранных личных встреч).
    - Олимпийская система (плей-офф) — система розыгрыша, при которой участник выбывает из борьбы после первого же проигрыша. Победителем становится команда, победившая в последнем круге.
- В случае, если команда не может принять участие в матче в установленном порядке в отведенное время, то с разрешения судей матч может быть перенесен после матча следующих двух команд, не более одного раза за весь этап и, если это не последний матч текущего тура.
- В случае неявки команды в отведенное время или отказа команды от участия объявляется победа команды соперников с максимально возможным счетом или счетом 2:0.

<a id="section-4-4"></a>

### 4.4. Порядок проведения соревнований со смешанной системой розыгрыша

- Виды соревнований со смешанной системой розыгрыша проводятся в 2 этапа:
    - Квалификационный этап. По его итогам формируется ранжированный список прошедших квалификацию участников, переходящих в финальный этап.
    - Финальный этап. Соревнуются участники прошедшие из квалификационного этапа. Число участников прошедших в финальный этап определяется организаторами.
- При проведении финального этапа по олимпийской системе пары участников составляются по принципу «лучший с худшим» согласно ранжированному списку прошедших в финал участников. Порядок расположения пар до 32 команд указан на рис. 1\

<a id="section-5"></a>

## 5. Дисквалификация

<a id="section-5-1"></a>

### 5.1. Основания для дисквалификации

- Общие основания для дисквалификации приведены в настоящем разделе.
- Дополнительные основания для дисквалификации приведены в конкретных регламентах к каждой дисциплине.

<a id="section-5-2"></a>

### 5.2. Дисквалификация роботов

- Дисквалификация производится по решению судьи.
- Организаторами может быть предоставлена возможность устранить нарушения до фактического начала соревнований. В случае устранения оснований дисквалификации робот допускается к продолжению состязаний. При повторном нарушении требований в период тех же соревнований в той же дисциплине робот дисквалифицируется окончательно.
- Робот должен быть дисквалифицирован в следующих случаях:
    - несоблюдение требований к размерам и массе
    - несоблюдение требований к безопасности конструктивного исполнения робота
    - робот имеет нестандартные средства коммуникации или телеуправления либо такие встроенные средства, как, например, BT, WiFi и т.п., не отключены, если это не требуется для коммуникации роботов между собой или роботов и участников в рамках соревнований
    - робот содержит устройство воспроизведения оскорбительных слов или изображений или воспроизводит их
    - на робота нанесены оскорбительные слова или изображения
    - робот не готов к соревновательным действиям в течение 30 секунд после объявления начала попытки (заезда, матча)

<a id="section-5-3"></a>

### 5.3. Дисквалификация участников

- Дисквалификация производится по решению судьи.
- Участник должен быть дисквалифицирован в следующих случаях:
    - грубое и агрессивное поведение;
    - нарушение правил поведения участников соревнований;
    - умышленная порча имущества других участников или организаторов соревнований;
    - грубое или неоднократное нарушение требований и запретов, установленных настоящим регламентом или регламентом конкретной дисциплины;
    - отказ или неспособность объяснить конструктивное исполнение и алгоритм действия робота, а также продемонстрировать загрузку программы в память робота.

<a id="section-6"></a>

## 6. Апелляции

<a id="section-6-1"></a>

### 6.1. Апелляция в общем порядке

- Во время проведения соревнований участники могут выражать несогласие с принятым судьей решением. Участник или руководитель команды, несогласный с решением судьи, может в устной форме обратиться за разъяснениями к судье, принявшему решение.
- Выступающая команда может обратиться за разъяснением во время проведения своей зачетной попытки или матча. Команда может обратиться за разъяснением относящимся к другой команде, только если она соревнуется в том же этапе и только между зачетными попытками.
- Допускается требовать разъяснения возможных нарушений, касающихся только положений опубликованных регламентов соревнований. Не допускается требовать в формате разъяснений или последующей апелляции проверки знаний участников другой команды, замены соревновательного оборудования или полигонов.
- Если на разъяснение решения судье требуется более одной минуты, разъяснение должно быть отложено до перерыва или конца этапа.
- Если данное судьей разъяснение не удовлетворяет участника или руководителя, он может выразить свое несогласие письменно в форме апелляции, обосновав его соответствующими положениями регламента соревнований. Апелляция подается на рассмотрение в апелляционную комиссию соревнований, а при ее отсутствии – главному судье соревнований.
- Подача апелляции допускается в отношении действий судьи, только если эти действия связаны с заявкой подающей апелляцию команды или с заявкой, которая влияет на результат указанной команды.
- Организаторами соревнований должно быть предусмотрено время на ознакомление с результатами соревнований и возможность подачи апелляций до окончания мероприятия.
- Апелляция, должна быть рассмотрена до окончания мероприятия.
- Апелляция, поданная после окончания соревнований, не рассматривается.
- Любые заявления с целью изменения результатов соревнований, не направленные в форме апелляции, не рассматриваются.
- Любые заявления, направленные после окончания мероприятия, могут быть рассмотрены организационным комитетом только с целью восстановления сроков подачи апелляций. В случае, если процедура проведения соревнований не позволяла подать апелляцию в установленный срок, организационный комитет, исходя из своих возможностей, может собрать апелляционную комиссию для рассмотрения заявления по существу.

<a id="section-6-2"></a>

### 6.2. Апелляция в срочном порядке

- Процедура апелляции в срочном порядке может быть инициирована только в случае, если участником оспаривается одно из следующих решений судьи:
    - о недопуске его к участию в соревнованиях (раунде соревнования) с парным участием;
    - о дисквалификации его (или его робота) с соревнований с парным участием, если участником не были сыграны все матчи данного соревнования;
    - о его поражении в соревновании с парным участием.
- При несогласии с разъяснением судьи, касающегося принятого решения, участник может обратиться в апелляционную комиссию с апелляционной жалобой в устной форме.
- Устная апелляция, поданная в срочном порядке, рассматривается не более 15 минут.

<a id="section-6-3"></a>

### 6.3. Рассмотрение апелляционных жалоб

- При рассмотрении апелляции апелляционная комиссия рассматривает доводы участника, содержащиеся в поданной апелляции.
- Участник может ссылаться на:
    - собственные медиаматериалы (фото и видео) в том случае, если во время проведения соревнований не была организована непрерывная съемка соревновательного полигона в качестве, достаточном для установления фактов, необходимых для принятия комиссией решения;
    - положения опубликованных на портале версий регламента данных соревнований и иных документов, если они распространяются на оспариваемое решение.
- Апелляционная комиссия при рассмотрении апелляции не обязана опираться на представленные участником фото- и видеоматериалы, но может принять их во внимание. Апелляционная комиссия при рассмотрении апелляции может потребовать от участника, судьи или других участников предоставить дополнительные материалы, дать дополнительные разъяснения. Апелляционная комиссия может возложить на участника, подавшего жалобу, обязанность самостоятельно найти других участников, разъяснения которых будут необходимы апелляционной комиссии для принятия решения.
- Апелляционная комиссия после рассмотрения жалобы выносит решение:
    - о согласии с решением судьи и об отказе в удовлетворении апелляции;
    - об отмене решения судьи и удовлетворении апелляции.
- Апелляционная комиссия в последнем случае может назначить переигровку и (или) признать недействительными оспариваемые в жалобе результаты.
- Если участник становится победителем по результатам апелляции, но после общего награждения, то ему присваивается соответствующее призовое место независимо от итогов награждения. Итоги общего награждения не пересматриваются.
- Решение апелляционной комиссии является окончательным и не подлежит дальнейшему обсуждению. В случае, если участник подает апелляцию по уже разрешенному апелляционной комиссией вопросу, комиссия вправе не принимать эту апелляцию.

<a id="appendix-a"></a>

## Приложение А. Проведение технического интервью

<a id="appendix-a-1"></a>

### А.1. Общие положения

- Техническое интервью проводится с целью подтверждения участниками команды самостоятельного проектирования, разработки робота и написания программы.
- Для целей технического интервью Организационным комитетом создается Техническая инспекция. В Техническую инспекцию могут входить отдельно приглашенные технические эксперты в области робототехники или судьи соревнований.
- В ходе технической инспекции участники должны доказать самостоятельную разработку программы и конструкции робота.
- В ходе технического интервью не проверяется объем знаний участников сверх использованных ими технических и программных решений.

<a id="appendix-a-2"></a>

### А.2. Общие требования

- Участник должен продемонстрировать понимание всех технических и программных решений, использованных в своем роботе.
- Участник должен уметь объяснить:
    - назначение основных узлов робота;
    - принцип работы используемых датчиков и исполнительных механизмов;
    - структуру программы;
    - назначение переменных, функций, классов и модулей программы;
    - используемые алгоритмы и логику принятия решений роботом;
    - процесс настройки и отладки робота.

<a id="appendix-a-3"></a>

### А.3. Требования к знаниям по программе

- Участник должен уметь:
    - объяснить назначение основных частей программного кода;
    - описать назначение ключевых переменных и параметров;
    - объяснить работу используемых алгоритмов;
    - объяснить выбор используемых методов решения задачи;
    - продемонстрировать понимание взаимодействия программы с датчиками и исполнительными механизмами.
- Если в программе используются регуляторы, фильтры, компьютерное зрение, нейронные сети или иные специализированные алгоритмы, участник должен понимать принципы их работы на уровне, достаточном для объяснения их назначения и применения в роботе.

<a id="appendix-a-4"></a>

### А.4. Общие требования к знаниям по конструкции робота

- Участник должен понимать и уметь объяснять:
    - назначение основных механических узлов;
    - назначение используемых датчиков;
    - назначение исполнительных механизмов;
    - причины выбора примененных технических решений.

<a id="appendix-a-5"></a>

### А.5. Роботы, собранные на базе образовательного конструктора

- Для роботов, созданных на базе образовательного конструктора, участник должен понимать и уметь объяснять:
    - назначение используемых электронных устройств;
    - принцип работы используемых датчиков;
    - способы подключения электронных устройств;
    - взаимодействие аппаратной части с программным обеспечением.
- Детальное знание внутреннего устройства компонентов, схемотехники и процесса их разработки не требуется.

<a id="appendix-a-6"></a>

### А.6. Роботы с собственной разработкой аппаратной части

- Если участник использует в роботе электронные устройства, печатные платы, датчики, драйвера, контроллеры или иные аппаратные компоненты собственной разработки, он должен быть готов объяснить:
    - назначение и принцип работы разработанных устройств;
    - особенности схемотехнических решений;
    - способы подключения и взаимодействия компонентов;
    - выбор элементной базы;
    - процесс проектирования, изготовления и отладки.
- Глубина вопросов может быть увеличена пропорционально объему самостоятельно выполненной разработки.

<a id="appendix-a-7"></a>

### А.7. Порядок проведения интервью

- Интервью проводится со всеми участниками команды.
- Экспертная комиссия вправе задавать вопросы по любому элементу конструкции робота и программы, используемых в роботе.
- Сложность и глубина вопросов определяются уровнем технической сложности примененных решений и объемом заявленной участником самостоятельной разработки.

<a id="appendix-a-8"></a>

### А.8. Основания для сомнений в авторстве

- Основанием для дополнительных вопросов может являться ситуация, когда участник:
    - не может объяснить назначение значительной части программного кода;
    - не понимает принцип работы используемых алгоритмов;
    - не может объяснить устройство и работу основных узлов робота;
    - не может объяснить собственные технические решения, заявленные как самостоятельно разработанные.
- По результатам интервью экспертная комиссия может сделать вывод о недостаточном подтверждении авторства проекта и дисквалифицировать команду.
