# Регламенты соревнований РобоФинист

Репозиторий для хранения регламентов соревнований портала [РобоФинист](https://robofinist.ru), истории их редакций и обсуждения изменений.

## Общий регламент

**[Общий регламент соревнований](general.md)** — версия **8.1 от 20.09.2026**.

Общий регламент дополняет частные регламенты дисциплин. При противоречиях приоритет имеет регламент конкретной дисциплины.

Актуальная действующая редакция общего регламента опубликована на [robofinist.ru/regmain](https://robofinist.ru/regmain).

## Работа с регламентами

- Для каждой дисциплины хранится отдельный файл в формате Markdown (`.md`).
- Версия, дата редакции и история изменений указываются в самом документе.
- После добавления регламента ссылка на него включается в таблицу выше.
- Предложения и замечания можно оформлять через [Issues](https://github.com/robofinist/regulations/issues), изменения — через pull request.

Вопросы по регламентам: [method@robofinist.ru](mailto:method@robofinist.ru).
