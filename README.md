# Регламенты соревнований РобоФинист

Репозиторий регламентов соревнований портала [РобоФинист](https://robofinist.ru). Документы организованы по профилям и учебным категориям; история редакций сохраняется в Git.

## Общий регламент

**[Общий регламент соревнований](general.md)** — версия **8.1 от 20.09.2026**.

Общий регламент дополняет частные регламенты дисциплин. При противоречиях приоритет имеет регламент конкретной дисциплины. Действующая редакция общего регламента опубликована на [robofinist.ru/regmain](https://robofinist.ru/regmain).

## Формат документов

- Каждый регламент хранится в отдельном файле Markdown (`.md`). Иллюстрации находятся в папке `assets` рядом с документом, отдельно для каждой дисциплины.
- Для документов, преобразованных из PDF, сохранены номера страниц и ссылка на исходный PDF для сверки таблиц и схем.
- Раздел «Вне профилей» содержит документ, который в исходном архиве находился вне папок профилей.
- Старые адреса двух ранее загруженных регламентов сохранены как страницы со ссылками на новое расположение.

Изменения подготавливаются в отдельной ветке и предлагаются через [pull request](https://github.com/robofinist/regulations/pulls). При изменении содержания регламента следует обновить его версию, дату и историю изменений, а также сведения в оглавлении.
